---
title: Tokage 1.2.5
slug: "1.2.5"
---

- Token totals now use each usage event's timestamp instead of trusting the folder the session log was created in.
- Long-running Codex goals that continue across days or months are now attributed to the exact date they were used.
- Improved log discovery so active older session files stay included without rescanning every historical session on each refresh.
